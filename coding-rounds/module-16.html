Problem 1: Distributed Rate Limiter

Token Bucket + Sliding Window, Per-Client/Per-Endpoint, Thread-Safe ▼

Problem Statement

Design a rate limiter library that can be embedded in a service. It must support:

  • Per-client AND per-endpoint rate limits (independent limits)
  • Two algorithms: Token Bucket (bursty traffic OK) and Sliding Window Log (strict)
  • Thread-safe for concurrent requests
  • Pluggable policy — easy to add new algorithms

Requirements Gathering Checklist

  • Is this in-process (single node) or distributed (Redis-backed)? Start in-process, design for extension.
  • Do limits reset at fixed windows or slide? Support both.
  • What's the cardinality of clients? Thousands — memory matters.
  • What happens on limit breach — block or return error code?
  • Do we need metrics/observability hooks?

Design Discussion

Token Bucket: Refill tokens at a fixed rate. Allows bursting up to bucket capacity. O(1) space per client.

Sliding Window Log: Store timestamps of every request in a deque. Evict timestamps older than window. Exact but O(limit) space per key.

Key abstraction: A RateLimitPolicy interface so any algorithm is swappable. A RateLimiter composes policies per (client, endpoint) key.

import java.util.ArrayDeque;
import java.util.Deque;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.locks.ReentrantLock;

// ── Policy Interface ──────────────────────────────────────────────────────────

/** Pluggable rate-limit algorithm. Implementations must be thread-safe. */
public interface RateLimitPolicy {
    boolean isAllowed();
}

// ── Token Bucket ──────────────────────────────────────────────────────────────

/** Allows short bursts; refills tokens at a steady rate (tokens/sec). */
public final class TokenBucketPolicy implements RateLimitPolicy {
    private final int capacity;
    private final double refillRate; // tokens per nanosecond
    private double tokens;
    private long lastRefillNanos;
    private final ReentrantLock lock = new ReentrantLock();

    public TokenBucketPolicy(int capacity, double refillPerSecond) {
        this.capacity = capacity;
        this.tokens = capacity;
        this.refillRate = refillPerSecond / 1_000_000_000.0;
        this.lastRefillNanos = System.nanoTime();
    }

    @Override
    public boolean isAllowed() {
        lock.lock();
        try {
            long now = System.nanoTime();
            long elapsed = now - lastRefillNanos;
            tokens = Math.min(capacity, tokens + elapsed * refillRate);
            lastRefillNanos = now;
            if (tokens >= 1.0) {
                tokens -= 1.0;
                return true;
            }
            return false;
        } finally {
            lock.unlock();
        }
    }
}

// ── Sliding Window Log ────────────────────────────────────────────────────────

/** Exact sliding window; stores timestamps of each request in a deque. */
public final class SlidingWindowPolicy implements RateLimitPolicy {
    private final int limit;
    private final long windowNanos;
    private final Deque<Long> timestamps = new ArrayDeque<>();
    private final ReentrantLock lock = new ReentrantLock();

    public SlidingWindowPolicy(int limit, long windowMillis) {
        this.limit = limit;
        this.windowNanos = windowMillis * 1_000_000L;
    }

    @Override
    public boolean isAllowed() {
        lock.lock();
        try {
            long now = System.nanoTime();
            long cutoff = now - windowNanos;
            while (!timestamps.isEmpty() && timestamps.peekFirst() < cutoff) {
                timestamps.pollFirst();
            }
            if (timestamps.size() < limit) {
                timestamps.addLast(now);
                return true;
            }
            return false;
        } finally {
            lock.unlock();
        }
    }
}

// ── Rate Limiter ──────────────────────────────────────────────────────────────

/**
 * Composes per-(clientId, endpoint) policies.
 * New algorithms are added via register() without touching this class (OCP).
 */
public final class RateLimiter {
    // ConcurrentHashMap for lock-free reads on the outer map
    private final Map<String, RateLimitPolicy> policies = new ConcurrentHashMap<>();

    public void register(String clientId, String endpoint, RateLimitPolicy policy) {
        policies.put(key(clientId, endpoint), policy);
    }

    /** Returns true if the request is allowed, false if rate-limited. */
    public boolean check(String clientId, String endpoint) {
        RateLimitPolicy policy = policies.get(key(clientId, endpoint));
        return policy == null || policy.isAllowed(); // no policy = allow
    }

    private static String key(String clientId, String endpoint) {
        return clientId + "::" + endpoint;
    }
}

    }

        TokenBucketPolicy policy = new TokenBucketPolicy(100, 0.0);
        AtomicInteger allowed = new AtomicInteger(0);
        ExecutorService exec = Executors.newFixedThreadPool(20);
        CountDownLatch latch = new CountDownLatch(200);

        for (int i = 0; i < 200; i++) {
            exec.submit(() -> {
                if (policy.isAllowed()) allowed.incrementAndGet();
                latch.countDown();
            });
        }
        latch.await(5, TimeUnit.SECONDS);
        exec.shutdown();
        assertEquals(100, allowed.get(), "Exactly 100 requests should be allowed");

Problem 2: Idempotency Framework

Idempotency Key Management, Request Deduplication, TTL Cleanup ▼

Problem Statement

Build a framework that payment APIs can use to make any operation idempotent. Given the same idempotency_key, the second call must return the same result as the first without re-executing the operation. Keys expire after a configurable TTL.

Requirements Gathering Checklist

  • Who generates the idempotency key — client or server?
  • What if the first request is still in-flight when the second arrives? (Must block, not duplicate)
  • How long do keys live? (Razorpay uses 24h)
  • Must the stored response be the full HTTP response or just the body?
  • What happens if the first request failed — is that result cached?

Design Discussion

State machine per key: PENDING → COMPLETE (or FAILED). A second request arriving during PENDING must wait, not re-execute — otherwise you get a double-charge.

Data structure: ConcurrentHashMap of key → IdempotencyRecord. Each record holds a CountDownLatch so concurrent callers block until the first finishes.

import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicReference;
import java.util.function.Supplier;

// ── State Machine ─────────────────────────────────────────────────────────────

public enum KeyState { PENDING, COMPLETE, FAILED }

// ── Record ────────────────────────────────────────────────────────────────────

/** Immutable snapshot stored per idempotency key. */
public final class IdempotencyRecord<T> {
    final KeyState state;
    final T result;
    final Throwable error;
    final long createdAtMillis;
    // Latch allows concurrent callers to wait for the first caller to finish
    final CountDownLatch done = new CountDownLatch(1);

    IdempotencyRecord() {
        this.state = KeyState.PENDING;
        this.result = null;
        this.error = null;
        this.createdAtMillis = System.currentTimeMillis();
    }

    IdempotencyRecord(T result, long createdAtMillis) {
        this.state = KeyState.COMPLETE;
        this.result = result;
        this.error = null;
        this.createdAtMillis = createdAtMillis;
    }

    IdempotencyRecord(Throwable error, long createdAtMillis) {
        this.state = KeyState.FAILED;
        this.result = null;
        this.error = error;
        this.createdAtMillis = createdAtMillis;
    }
}

// ── Store ─────────────────────────────────────────────────────────────────────

/**
 * Thread-safe idempotency store with TTL-based expiry.
 *
 * <p>First caller executes the operation; subsequent callers with the same key
 * block on the CountDownLatch and receive the cached result.</p>
 */
public final class IdempotencyStore<T> {
    private final long ttlMillis;
    private final ConcurrentHashMap<String, IdempotencyRecord<T>> store =
            new ConcurrentHashMap<>();

    public IdempotencyStore(long ttlMillis) {
        this.ttlMillis = ttlMillis;
    }

    /**
     * Execute {@code operation} exactly once for the given key.
     * Concurrent callers with the same key wait for the first result.
     */
    public T execute(String key, Supplier<T> operation) throws Exception {
        evictExpired();

        IdempotencyRecord<T> pending = new IdempotencyRecord<>();
        // putIfAbsent: only first caller inserts the PENDING record
        IdempotencyRecord<T> existing = store.putIfAbsent(key, pending);

        if (existing != null) {
            // Not the first caller — wait for the first to complete (30s timeout)
            existing.done.await(30, TimeUnit.SECONDS);
            if (existing.state == KeyState.COMPLETE) return existing.result;
            throw new RuntimeException("Idempotent operation failed",
                    existing.error != null ? existing.error : new RuntimeException("unknown"));
        }

        // We are the first caller — run the operation outside any lock
        try {
            T result = operation.get();
            IdempotencyRecord<T> completed =
                    new IdempotencyRecord<>(result, pending.createdAtMillis);
            store.put(key, completed);
            pending.done.countDown(); // unblock waiters (they will re-read from map)
            return result;
        } catch (Exception ex) {
            IdempotencyRecord<T> failed =
                    new IdempotencyRecord<>(ex, pending.createdAtMillis);
            store.put(key, failed);
            pending.done.countDown();
            throw ex;
        }
    }

    public KeyState getState(String key) {
        IdempotencyRecord<T> rec = store.get(key);
        return rec == null ? null : rec.state;
    }

    private void evictExpired() {
        long now = System.currentTimeMillis();
        store.entrySet().removeIf(e -> now - e.getValue().createdAtMillis > ttlMillis);
    }
}

import org.junit.jupiter.api.Test;
import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicInteger;
import static org.junit.jupiter.api.Assertions.*;

class IdempotencyStoreTest {

    @Test
    void basicIdempotency() throws Exception {
        IdempotencyStore<String> store = new IdempotencyStore<>(60_000);
        AtomicInteger callCount = new AtomicInteger(0);

        String r1 = store.execute("key-001", () -> "result-" + callCount.incrementAndGet());
        String r2 = store.execute("key-001", () -> "result-" + callCount.incrementAndGet());

        assertEquals(r1, r2, "Same key must return identical result");
        assertEquals(1, callCount.get(), "Operation must execute exactly once");
    }

    @Test
    void differentKeysExecuteIndependently() throws Exception {
        IdempotencyStore<Integer> store = new IdempotencyStore<>(60_000);
        assertEquals(0,  store.execute("key-0", () -> 0));
        assertEquals(10, store.execute("key-1", () -> 10));
        assertEquals(20, store.execute("key-2", () -> 20));
    }

    @Test
    void ttlExpiryAllowsReexecution() throws Exception {
        IdempotencyStore<Integer> store = new IdempotencyStore<>(50); // 50ms TTL
        AtomicInteger count = new AtomicInteger(0);
        store.execute("exp-key", () -> count.incrementAndGet());
        Thread.sleep(100);
        store.execute("exp-key", () -> count.incrementAndGet());
        assertEquals(2, count.get(), "Should re-execute after TTL expires");
    }

    @Test
    void concurrentSameKeyExecutesOnce() throws Exception {
        IdempotencyStore<Integer> store = new IdempotencyStore<>(60_000);
        AtomicInteger callCount = new AtomicInteger(0);
        int threads = 10;
        ExecutorService exec = Executors.newFixedThreadPool(threads);
        CountDownLatch start = new CountDownLatch(1);
        CopyOnWriteArrayList<Integer> results = new CopyOnWriteArrayList<>();

        for (int i = 0; i < threads; i++) {
            exec.submit(() -> {
                try {
                    start.await();
                    results.add(store.execute("concurrent-key", () -> {
                        Thread.sleep(50);
                        return callCount.incrementAndGet();
                    }));
                } catch (Exception ignored) {}
            });
        }
        start.countDown();
        exec.shutdown();
        exec.awaitTermination(5, TimeUnit.SECONDS);

        assertEquals(1, callCount.get(), "Operation must run exactly once under concurrency");
        assertTrue(results.stream().allMatch(r -> r == 1), "All callers must get the same result");
    }
}

Problem 3: Webhook Delivery Engine

Reliable Delivery, Exponential Backoff, DLQ, Circuit Breaker, Signature Verification ▼

Problem Statement

Build a webhook delivery engine for Razorpay. When a payment succeeds, a POST must be delivered to the merchant's URL. Requirements: at-least-once delivery, exponential backoff retries, dead-letter queue after max retries, HMAC signature on each request, per-endpoint circuit breaker to avoid hammering failing merchants.

Requirements Gathering Checklist

  • At-most-once or at-least-once? (Usually at-least-once; merchant must be idempotent)
  • What's the retry schedule? (e.g., 1s, 2s, 4s, 8s … up to 24h)
  • How long before a DLQ entry is discarded?
  • How do we verify the merchant received it? (HTTP 2xx = success)
  • Do we need ordering per-merchant?
import javax.crypto.Mac;
import javax.crypto.spec.SecretKeySpec;
import java.nio.charset.StandardCharsets;
import java.util.*;
import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicInteger;
import java.util.concurrent.locks.ReentrantLock;
import java.util.function.BiFunction;

// ── Circuit Breaker ───────────────────────────────────────────────────────────

public enum CircuitState { CLOSED, OPEN, HALF_OPEN }

public final class CircuitBreaker {
    private final int failureThreshold;
    private final long recoveryTimeoutMs;
    private volatile CircuitState state = CircuitState.CLOSED;
    private final AtomicInteger failures = new AtomicInteger(0);
    private volatile long openedAtMs = 0L;
    private final ReentrantLock lock = new ReentrantLock();

    public CircuitBreaker(int failureThreshold, long recoveryTimeoutMs) {
        this.failureThreshold = failureThreshold;
        this.recoveryTimeoutMs = recoveryTimeoutMs;
    }

    public boolean allowRequest() {
        lock.lock();
        try {
            if (state == CircuitState.CLOSED) return true;
            if (state == CircuitState.OPEN) {
                if (System.currentTimeMillis() - openedAtMs > recoveryTimeoutMs) {
                    state = CircuitState.HALF_OPEN;
                    return true;
                }
                return false;
            }
            return true; // HALF_OPEN: let the probe through
        } finally { lock.unlock(); }
    }

    public void recordSuccess() {
        lock.lock();
        try { failures.set(0); state = CircuitState.CLOSED; }
        finally { lock.unlock(); }
    }

    public void recordFailure() {
        lock.lock();
        try {
            failures.incrementAndGet();
            if (failures.get() >= failureThreshold || state == CircuitState.HALF_OPEN) {
                state = CircuitState.OPEN;
                openedAtMs = System.currentTimeMillis();
                failures.set(0);
            }
        } finally { lock.unlock(); }
    }

    public CircuitState getState() { return state; }
}

// ── Domain ────────────────────────────────────────────────────────────────────

public record WebhookEvent(
    String eventId,
    String endpointUrl,
    Map<String, Object> payload,
    String secret,
    int maxAttempts
) {}

// ── Engine ────────────────────────────────────────────────────────────────────

/**
 * Delivers webhooks with exponential backoff, per-endpoint circuit breakers,
 * HMAC-SHA256 signatures, and a dead-letter queue.
 *
 * <p>The {@code httpCaller} is injectable to avoid real network calls in tests.</p>
 */
public final class WebhookDeliveryEngine {
    private static final long BASE_DELAY_MS = 1_000L;

    // Injectable HTTP caller: (url, payloadJson, signature) -> success
    private final BiFunction<String, String, Boolean> httpCaller;
    private final ConcurrentHashMap<String, CircuitBreaker> circuits = new ConcurrentHashMap<>();
    private final CopyOnWriteArrayList<WebhookEvent> dlq = new CopyOnWriteArrayList<>();
    private final ExecutorService executor = Executors.newCachedThreadPool();

    public WebhookDeliveryEngine(BiFunction<String, String, Boolean> httpCaller) {
        this.httpCaller = httpCaller;
    }

    public Future<?> enqueueAsync(WebhookEvent event) {
        return executor.submit(() -> deliver(event));
    }

    public void deliver(WebhookEvent event) {
        CircuitBreaker circuit = circuits.computeIfAbsent(
            event.endpointUrl(), url -> new CircuitBreaker(5, 60_000L));

        for (int attempt = 0; attempt < event.maxAttempts(); attempt++) {
            if (!circuit.allowRequest()) {
                if (attempt == event.maxAttempts() - 1) { dlq.add(event); return; }
                sleep(BASE_DELAY_MS * (1L << attempt));
                continue;
            }

            String payloadJson = toJson(event.payload());
            String signature   = hmacSha256(payloadJson, event.secret());
            boolean success    = httpCaller.apply(payloadJson, signature);

            if (success) { circuit.recordSuccess(); return; }

            circuit.recordFailure();
            if (attempt < event.maxAttempts() - 1) sleep(BASE_DELAY_MS * (1L << attempt));
        }
        dlq.add(event);
    }

    public List<WebhookEvent> getDlq() { return Collections.unmodifiableList(dlq); }

    // ── Helpers ───────────────────────────────────────────────────────────────

    static String hmacSha256(String data, String secret) {
        try {
            Mac mac = Mac.getInstance("HmacSHA256");
            mac.init(new SecretKeySpec(secret.getBytes(StandardCharsets.UTF_8), "HmacSHA256"));
            byte[] hash = mac.doFinal(data.getBytes(StandardCharsets.UTF_8));
            StringBuilder sb = new StringBuilder();
            for (byte b : hash) sb.append(String.format("%02x", b));
            return sb.toString();
        } catch (Exception e) { throw new RuntimeException(e); }
    }

    /** Deterministic JSON: sorts keys alphabetically for a stable signature. */
    static String toJson(Map<String, Object> map) {
        StringBuilder sb = new StringBuilder("{");
        new TreeMap<>(map).forEach((k, v) ->
            sb.append("\"").append(k).append("\":").append(jsonValue(v)).append(","));
        if (sb.charAt(sb.length() - 1) == ',') sb.deleteCharAt(sb.length() - 1);
        return sb.append("}").toString();
    }

    private static String jsonValue(Object v) {
        if (v instanceof String s) return "\"" + s + "\"";
        return String.valueOf(v);
    }

    private static void sleep(long ms) {
        try { Thread.sleep(ms); } catch (InterruptedException e) { Thread.currentThread().interrupt(); }
    }
}

import org.junit.jupiter.api.Test;
import static org.junit.jupiter.api.Assertions.*;

class WebhookDeliveryEngineTest {

    @Test
    void successfulDeliveryNoDlq() {
        WebhookDeliveryEngine engine = new WebhookDeliveryEngine((json, sig) -> true);
        WebhookEvent evt = new WebhookEvent("e1", "https://merchant.com/hook",
                Map.of("amount", 100), "secret", 3);
        engine.deliver(evt);
        assertTrue(engine.getDlq().isEmpty());
    }

    @Test
    void dlqAfterMaxRetries() {
        WebhookDeliveryEngine engine = new WebhookDeliveryEngine((json, sig) -> false);
        WebhookEvent evt = new WebhookEvent("e2", "https://bad.com/hook",

        engine.deliver(evt); // sleeps are fast because delivery fails instantly
        assertEquals(1, engine.getDlq().size());
    }

    @Test
    void hmacSignatureIsDeterministic() {
        // Key order must not affect the signature
        String sig1 = WebhookDeliveryEngine.hmacSha256(
                WebhookDeliveryEngine.toJson(new HashMap<>(Map.of("b", 2, "a", 1))), "secret");
        String sig2 = WebhookDeliveryEngine.hmacSha256(
                WebhookDeliveryEngine.toJson(new HashMap<>(Map.of("a", 1, "b", 2))), "secret");
        assertEquals(sig1, sig2, "Signatures must be key-order independent");
    }

    @Test
    void circuitBreakerTripsAfterThreshold() {
        CircuitBreaker cb = new CircuitBreaker(3, 999_999L);
        cb.recordFailure(); cb.recordFailure(); cb.recordFailure();
        assertFalse(cb.allowRequest(), "Circuit should be OPEN after threshold");
    }

    @Test
    void circuitBreakerRecoversAfterTimeout() throws InterruptedException {
        CircuitBreaker cb = new CircuitBreaker(1, 50L);
        cb.recordFailure();
        assertFalse(cb.allowRequest());
        Thread.sleep(100);
        assertTrue(cb.allowRequest(), "Circuit should probe after recovery timeout");
        cb.recordSuccess();
        assertTrue(cb.allowRequest(), "Circuit should be CLOSED after success");
    }

Problem 4: Configurable Rule Engine

AST-Based Evaluation, AND/OR/NOT, Hot-Reload, Rule Versioning ▼

Problem Statement

Build a rule engine used by the fraud detection team. Rules are defined in JSON (so non-engineers can write them). The engine evaluates rules against a transaction context. Support AND, OR, NOT combinators and comparison operators. Rules must be hot-reloadable (no restart) and versioned.

Requirements Gathering Checklist

  • What types of values appear in rules? (numbers, strings, lists for "in" operator)
  • Who writes rules — engineers or ops? (Determines complexity of DSL)
  • What's the performance target? (Thousands of rules per second)
  • Can a rule reference another rule (rule composition)?
  • What happens when a rule has an error — fail open or closed?
import java.util.*;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.atomic.AtomicInteger;
import java.util.concurrent.locks.ReadWriteLock;
import java.util.concurrent.locks.ReentrantReadWriteLock;

// ── Context ───────────────────────────────────────────────────────────────────

/** Immutable evaluation context for a transaction. */
public record EvalContext(Map<String, Object> fields) {
    public Object get(String field) { return fields.get(field); }
}

// ── AST Node Hierarchy ────────────────────────────────────────────────────────

/** Sealed hierarchy for the rule AST — exhaustive, type-safe. */
public sealed interface RuleNode permits AndNode, OrNode, NotNode, ConditionNode {
    boolean evaluate(EvalContext ctx);
}

public record AndNode(List<RuleNode> children) implements RuleNode {
    @Override public boolean evaluate(EvalContext ctx) {
        return children.stream().allMatch(c -> c.evaluate(ctx));
    }
}

public record OrNode(List<RuleNode> children) implements RuleNode {
    @Override public boolean evaluate(EvalContext ctx) {
        return children.stream().anyMatch(c -> c.evaluate(ctx));
    }
}

public record NotNode(RuleNode child) implements RuleNode {
    @Override public boolean evaluate(EvalContext ctx) {
        return !child.evaluate(ctx);
    }
}

// ── Comparison Operators ──────────────────────────────────────────────────────

public enum Operator {
    EQ, NE, GT, LT, GTE, LTE, IN, NOT_IN;

    @SuppressWarnings("unchecked")
    public boolean apply(Object field, Object value) {
        return switch (this) {
            case EQ     -> Objects.equals(field, value);
            case NE     -> !Objects.equals(field, value);
            case GT     -> compare(field, value) > 0;
            case LT     -> compare(field, value) < 0;
            case GTE    -> compare(field, value) >= 0;
            case LTE    -> compare(field, value) <= 0;
            case IN     -> value instanceof Collection<?> c && c.contains(field);
            case NOT_IN -> !(value instanceof Collection<?> c && c.contains(field));
        };
    }

    @SuppressWarnings({"unchecked", "rawtypes"})
    private static int compare(Object a, Object b) {
        if (a instanceof Comparable ca && b instanceof Comparable cb) return ca.compareTo(cb);
        throw new IllegalArgumentException("Cannot compare " + a + " with " + b);
    }
}

public record ConditionNode(String field, Operator op, Object value) implements RuleNode {
    @Override public boolean evaluate(EvalContext ctx) {
        Object fieldValue = ctx.get(field);
        return fieldValue != null && op.apply(fieldValue, value);
    }
}

// ── Parser: Map -> AST ────────────────────────────────────────────────────────

public final class RuleParser {
    public static RuleNode parse(Map<String, Object> spec) {
        String type = (String) spec.get("type");
        return switch (type) {
            case "and" -> {
                List<Map<String, Object>> rules = castList(spec.get("rules"));
                yield new AndNode(rules.stream().map(RuleParser::parse).toList());
            }
            case "or" -> {
                List<Map<String, Object>> rules = castList(spec.get("rules"));
                yield new OrNode(rules.stream().map(RuleParser::parse).toList());
            }
            case "not" -> {
                Map<String, Object> child = castMap(spec.get("rule"));
                yield new NotNode(parse(child));
            }
            case "condition" -> {
                String field = (String) spec.get("field");
                Operator op  = Operator.valueOf(((String) spec.get("op")).toUpperCase());
                Object value = spec.get("value");
                yield new ConditionNode(field, op, value);
            }
            default -> throw new IllegalArgumentException("Unknown node type: " + type);
        };
    }

    @SuppressWarnings("unchecked")
    private static List<Map<String, Object>> castList(Object o) { return (List<Map<String, Object>>) o; }
    @SuppressWarnings("unchecked")
    private static Map<String, Object> castMap(Object o) { return (Map<String, Object>) o; }
}

// ── Registry with Hot-Reload ──────────────────────────────────────────────────

public final class RuleRegistry {
    private record VersionedRule(int version, RuleNode node) {}

    private final ConcurrentHashMap<String, VersionedRule> rules = new ConcurrentHashMap<>();
    private final ReadWriteLock rwLock = new ReentrantReadWriteLock();

    /** Parse and register (or hot-reload) a rule. Returns new version number. */
    public int register(String name, Map<String, Object> spec) {
        RuleNode node = RuleParser.parse(spec); // parse outside lock — may throw
        rwLock.writeLock().lock();
        try {
            int newVersion = rules.getOrDefault(name, new VersionedRule(0, null)).version() + 1;
            rules.put(name, new VersionedRule(newVersion, node));
            return newVersion;
        } finally { rwLock.writeLock().unlock(); }
    }

    public boolean evaluate(String name, EvalContext ctx) {
        rwLock.readLock().lock();
        try {
            VersionedRule vr = rules.get(name);
            if (vr == null) throw new NoSuchElementException("Rule not found: " + name);
            return vr.node().evaluate(ctx);
        } finally { rwLock.readLock().unlock(); }
    }

    public int getVersion(String name) {
        rwLock.readLock().lock();
        try {
            VersionedRule vr = rules.get(name);
            return vr == null ? -1 : vr.version();
        } finally { rwLock.readLock().unlock(); }
    }
}

Problem 5: Double-Entry Ledger

Multi-Currency, Audit Trail, Balance Consistency, Transaction Rollback ▼

Problem Statement

Implement a double-entry bookkeeping ledger. Every financial transaction creates two equal and opposite entries (debit one account, credit another). The sum of all debits must always equal the sum of all credits. Support multi-currency, an immutable audit trail, and balance lookups. Transactions must be atomic — either both entries are recorded or neither.

Requirements Gathering Checklist

  • Do we support partial transactions (split across N accounts)?
  • Is currency conversion in-scope? (Assume fixed exchange rates for now)
  • Do balances go negative? (Liability accounts can; asset accounts shouldn't)
  • What's the precision requirement? (Use BigDecimal, not double)
  • Is the audit trail append-only (regulatory requirement)?
import java.math.BigDecimal;
import java.time.Instant;

public enum EntryType { DEBIT, CREDIT }

/** Immutable audit record — never mutated after creation. */
public record LedgerEntry(
    String entryId,
    String transactionId,
    String accountId,
    EntryType type,
    BigDecimal amount,   // always positive
    String currency,
    Instant timestamp,
    String description

// ── Account ───────────────────────────────────────────────────────────────────

public final class Account {
    private final String accountId;
    private final String currency;
    private final boolean allowNegative; // true for liability/equity accounts
    private BigDecimal balance = BigDecimal.ZERO;
    final ReentrantLock lock = new ReentrantLock();

    public Account(String accountId, String currency, boolean allowNegative) {
        this.accountId = accountId;
        this.currency = currency;
        this.allowNegative = allowNegative;
    }

    public String getAccountId()  { return accountId;     }
    public String getCurrency()   { return currency;      }
    public boolean allowsNegative() { return allowNegative; }

    /** Called only while holding this account's lock. */
    BigDecimal getBalance() { return balance; }
    void applyDelta(BigDecimal delta) { balance = balance.add(delta); }
}

// ── Ledger ────────────────────────────────────────────────────────────────────

/**
 * Double-entry ledger: every debit must have a matching credit.
 * All entries for a transaction are committed atomically under sorted account locks
 * (lock ordering prevents deadlocks).
 */
public final class Ledger {
    private final ConcurrentHashMap<String, Account> accounts = new ConcurrentHashMap<>();
    // CopyOnWriteArrayList gives a cheap snapshot for audit queries
    private final CopyOnWriteArrayList<LedgerEntry> entries = new CopyOnWriteArrayList<>();

    public void createAccount(String accountId, String currency, boolean allowNegative) {
        if (accounts.putIfAbsent(accountId, new Account(accountId, currency, allowNegative)) != null)
            throw new LedgerError("Account already exists: " + accountId);
    }

    /**
     * Post a balanced transaction atomically.
     *
     * @param entrySpecs list of maps with keys: account, type ("debit"|"credit"), amount, desc
     * @return transactionId
     */
    public String postTransaction(List<Map<String, Object>> entrySpecs, String description) {
        // --- 1. Validate specs and resolve accounts -------------------------
        List<EntrySpec> specs = new ArrayList<>();
        Set<String> accountIds = new LinkedHashSet<>();
        for (Map<String, Object> raw : entrySpecs) {
            String accountId = (String) raw.get("account");
            Account acct = accounts.get(accountId);
            if (acct == null) throw new LedgerError("Unknown account: " + accountId);
            BigDecimal amount = new BigDecimal(raw.get("amount").toString());
            if (amount.compareTo(BigDecimal.ZERO) <= 0) throw new LedgerError("Amount must be positive");
            EntryType type = "debit".equals(raw.get("type")) ? EntryType.DEBIT : EntryType.CREDIT;
            specs.add(new EntrySpec(accountId, acct, type, amount,
                    (String) raw.getOrDefault("desc", description)));
            accountIds.add(accountId);
        }

        // --- 2. Compute net deltas per account -----------------------------
        Map<String, BigDecimal> deltas = new LinkedHashMap<>();
        BigDecimal netCheck = BigDecimal.ZERO;
        for (EntrySpec s : specs) {
            BigDecimal signed = s.type == EntryType.DEBIT ? s.amount.negate() : s.amount;
            deltas.merge(s.accountId, signed, BigDecimal::add);
            netCheck = netCheck.add(signed);
        }
        if (netCheck.compareTo(BigDecimal.ZERO) != 0)
            throw new LedgerError("Transaction does not balance: net=" + netCheck);

        // --- 3. Acquire locks in consistent order (sort by accountId) ------
        List<Account> locked = accountIds.stream()
                .map(accounts::get).sorted(Comparator.comparing(Account::getAccountId))
                .collect(Collectors.toList());
        locked.forEach(a -> a.lock.lock());

        try {
            // --- 4. Pre-flight: check no account goes negative -------------
            for (Map.Entry<String, BigDecimal> e : deltas.entrySet()) {
                Account acct = accounts.get(e.getKey());
                BigDecimal newBalance = acct.getBalance().add(e.getValue());
                if (!acct.allowsNegative() && newBalance.compareTo(BigDecimal.ZERO) < 0)
                    throw new LedgerError("Insufficient funds in " + e.getKey() +
                            ": balance=" + acct.getBalance() + " delta=" + e.getValue());
            }

            // --- 5. Commit --------------------------------------------------
            String txnId = UUID.randomUUID().toString();
            Instant now = Instant.now();
            List<LedgerEntry> newEntries = new ArrayList<>();
            for (EntrySpec s : specs) {
                newEntries.add(new LedgerEntry(UUID.randomUUID().toString(), txnId,
                        s.accountId, s.type, s.amount, s.account.getCurrency(), now, s.desc));
            }
            deltas.forEach((id, delta) -> accounts.get(id).applyDelta(delta));
            entries.addAll(newEntries);
            return txnId;
        } finally {
            locked.forEach(a -> a.lock.unlock());
        }
    }

    public BigDecimal getBalance(String accountId) {
        Account acct = accounts.get(accountId);
        if (acct == null) throw new LedgerError("Unknown account: " + accountId);
        acct.lock.lock();
        try { return acct.getBalance(); } finally { acct.lock.unlock(); }
    }

    public List<LedgerEntry> getAuditTrail(String accountId) {
        return entries.stream()
                .filter(e -> accountId == null || e.accountId().equals(accountId))
                .toList();
    }

    private record EntrySpec(String accountId, Account account, EntryType type,
                              BigDecimal amount, String desc) {}
}

Problem 6: Circuit Breaker Framework

Closed/Open/Half-Open States, Configurable Thresholds, Metrics Hooks ▼

Problem Statement

Build a production-grade circuit breaker that wraps any callable. When failure rate exceeds a threshold, the circuit opens and subsequent calls fail fast. After a recovery timeout, one probe request is allowed; if it succeeds the circuit closes. Emit metrics at each state transition for observability.

Requirements Gathering Checklist

  • Count-based or rate-based threshold? (Count is simpler; rate is more accurate)
  • What counts as a failure — exception only, or HTTP 5xx too?
  • Should the breaker be per-instance or a singleton registry?
  • What's the fallback when the circuit is open?
  • How do we surface current state to health-check endpoints?
import java.time.Instant;
import java.util.*;
import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicInteger;
import java.util.concurrent.atomic.AtomicLong;
import java.util.concurrent.atomic.AtomicReference;
import java.util.concurrent.locks.ReentrantLock;
import java.util.function.Supplier;

// ── States ────────────────────────────────────────────────────────────────────

public enum CircuitState { CLOSED, OPEN, HALF_OPEN }

public final class CircuitOpenException extends RuntimeException {
    public CircuitOpenException(String msg) { super(msg); }
}

// ── Metrics ───────────────────────────────────────────────────────────────────

public record MetricEvent(String name, String breaker, String detail, Instant ts) {}

public interface MetricsListener {
    void onEvent(MetricEvent event);
}

// ── Circuit Breaker ───────────────────────────────────────────────────────────

/**
 * Wraps any {@link Supplier} with circuit-breaker semantics.
 *
 * <ul>
 *   <li>CLOSED   — normal; tracks failures</li>
 *   <li>OPEN     — fail-fast; re-checks after {@code recoveryTimeoutMs}</li>
 *   <li>HALF_OPEN — allows one probe; success -> CLOSED, failure -> OPEN</li>
 * </ul>
 */
public final class CircuitBreaker {
    private final String name;
    private final int failureThreshold;
    private final long recoveryTimeoutMs;
    private final Set<Class<? extends Throwable>> monitoredExceptions;
    private final List<MetricsListener> listeners;

    private final AtomicReference<CircuitState> state =
            new AtomicReference<>(CircuitState.CLOSED);
    private final AtomicInteger failureCount = new AtomicInteger(0);
    private final AtomicLong lastFailureMs = new AtomicLong(0L);
    private final ReentrantLock transitionLock = new ReentrantLock();

    public CircuitBreaker(String name, int failureThreshold, long recoveryTimeoutMs,
                          Set<Class<? extends Throwable>> monitoredExceptions,
                          List<MetricsListener> listeners) {
        this.name = name;
        this.failureThreshold = failureThreshold;
        this.recoveryTimeoutMs = recoveryTimeoutMs;
        this.monitoredExceptions = monitoredExceptions;
        this.listeners = listeners;
    }

    /** Convenience constructor with defaults. */
    public CircuitBreaker(String name) {
        this(name, 5, 60_000L, Set.of(Exception.class), List.of());
    }

    public <T> T call(Supplier<T> action) {
        checkState();
        try {
            T result = action.get();
            onSuccess();
            return result;
        } catch (Throwable t) {
            if (isMonitored(t)) onFailure();
            throw t;
        }
    }

    public CircuitState getState() { return state.get(); }

    // ── Internal ──────────────────────────────────────────────────────────────

    private void checkState() {
        CircuitState current = state.get();
        if (current == CircuitState.CLOSED) return;
        if (current == CircuitState.OPEN) {
            long elapsed = System.currentTimeMillis() - lastFailureMs.get();
            if (elapsed > recoveryTimeoutMs) {
                transition(CircuitState.OPEN, CircuitState.HALF_OPEN);
                return; // allow probe
            }
            emit("rejected", "circuit OPEN, retry in " + (recoveryTimeoutMs - elapsed) + "ms");
            throw new CircuitOpenException(
                "Circuit '" + name + "' is OPEN. Retry in " + (recoveryTimeoutMs - elapsed) + "ms");
        }
        // HALF_OPEN: let one probe through (no throw)
    }

    private void onSuccess() {
        transitionLock.lock();
        try {
            failureCount.set(0);
            CircuitState prev = state.getAndSet(CircuitState.CLOSED);
            if (prev != CircuitState.CLOSED) emit("state_change", prev + " -> CLOSED");
            else emit("success", "");
        } finally { transitionLock.unlock(); }
    }

    private void onFailure() {
        transitionLock.lock();
        try {
            int count = failureCount.incrementAndGet();
            lastFailureMs.set(System.currentTimeMillis());
            emit("failure", "count=" + count);
            if (count >= failureThreshold || state.get() == CircuitState.HALF_OPEN) {
                transition(state.get(), CircuitState.OPEN);
                failureCount.set(0);
            }
        } finally { transitionLock.unlock(); }
    }

    private void transition(CircuitState from, CircuitState to) {
        state.set(to);
        emit("state_change", from + " -> " + to);
    }

    private boolean isMonitored(Throwable t) {
        return monitoredExceptions.stream().anyMatch(c -> c.isInstance(t));
    }

    private void emit(String event, String detail) {
        MetricEvent me = new MetricEvent(event, name, detail, Instant.now());
        listeners.forEach(l -> l.onEvent(me));
    }
}

// ── Singleton Registry ────────────────────────────────────────────────────────

public final class CircuitBreakerRegistry {
    private static final CircuitBreakerRegistry INSTANCE = new CircuitBreakerRegistry();
    private final ConcurrentHashMap<String, CircuitBreaker> breakers = new ConcurrentHashMap<>();

    private CircuitBreakerRegistry() {}
    public static CircuitBreakerRegistry getInstance() { return INSTANCE; }

    public CircuitBreaker getOrCreate(String name, int threshold, long timeoutMs) {
        return breakers.computeIfAbsent(name,
            n -> new CircuitBreaker(n, threshold, timeoutMs, Set.of(Exception.class), List.of()));
    }

    public Map<String, String> allStates() {
        Map<String, String> out = new LinkedHashMap<>();
        breakers.forEach((n, cb) -> out.put(n, cb.getState().name()));
        return Collections.unmodifiableMap(out);
    }
}

import java.util.*;
import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicBoolean;
import java.util.concurrent.atomic.AtomicInteger;
import java.util.concurrent.locks.ReentrantLock;

// ── Status ────────────────────────────────────────────────────────────────────

public enum JobStatus { PENDING, WAITING_DEPS, RUNNING, DONE, FAILED }

// ── Job ───────────────────────────────────────────────────────────────────────

public final class Job implements Comparable<Job> {
    public final String jobId = UUID.randomUUID().toString();
    public final Runnable task;
    public final int priority;          // higher = more urgent
    public final int maxRetries;
    public final long retryDelayMs;
    public final Set<String> dependencies; // job IDs that must be DONE first

    volatile long runAtMs;              // epoch ms when this job becomes eligible
    volatile JobStatus status;
    final AtomicInteger attempts = new AtomicInteger(0);

    public Job(Runnable task, long runAtMs, int priority, int maxRetries,
               long retryDelayMs, Set<String> dependencies) {
        this.task = task;
        this.runAtMs = runAtMs;
        this.priority = priority;
        this.maxRetries = maxRetries;
        this.retryDelayMs = retryDelayMs;
        this.dependencies = Collections.unmodifiableSet(new HashSet<>(dependencies));
        this.status = dependencies.isEmpty() ? JobStatus.PENDING : JobStatus.WAITING_DEPS;
    }

    /** Heap ordering: earliest runAt first, then highest priority. */
    @Override
    public int compareTo(Job other) {
        int cmp = Long.compare(this.runAtMs, other.runAtMs);
        return cmp != 0 ? cmp : Integer.compare(other.priority, this.priority); // desc priority
    }
}

// ── Leader Election Stub ──────────────────────────────────────────────────────

/**
 * Simplified leader election for single-node mode.
 * Production: replace with Redis SET NX EX + heartbeat, or etcd lease.
 */
public final class LeaderElection {
    private final String nodeId;
    private final AtomicBoolean isLeader = new AtomicBoolean(false);

    public LeaderElection(String nodeId) { this.nodeId = nodeId; }

    public boolean campaign() { return isLeader.compareAndSet(false, true); }
    public boolean isLeader() { return isLeader.get(); }
    public void resign()      { isLeader.set(false); }
    public String getNodeId() { return nodeId; }
}

// ── Scheduler ─────────────────────────────────────────────────────────────────

/**
 * Priority-based job scheduler with dependency resolution and retry backoff.
 *
 * <p>Architecture: one dispatcher thread polls the heap and promotes ready jobs
 * to a worker pool via a {@link BlockingQueue}. Workers execute jobs and handle retries.</p>
 */
public final class JobScheduler {
    private final PriorityQueue<Job> heap = new PriorityQueue<>();
    private final ConcurrentHashMap<String, Job> jobIndex = new ConcurrentHashMap<>();
    private final BlockingQueue<Job> readyQueue = new LinkedBlockingQueue<>();
    private final ReentrantLock heapLock = new ReentrantLock();
    private final LeaderElection election;
    private final ExecutorService workers;
    private volatile boolean running = false;
    private Thread dispatcherThread;

    public JobScheduler(int workerCount, String nodeId) {
        this.election = new LeaderElection(nodeId);
        this.workers = Executors.newFixedThreadPool(workerCount);
    }

    // ── Lifecycle ─────────────────────────────────────────────────────────────

    public void start() {
        if (!election.campaign()) throw new IllegalStateException("Failed to acquire leadership");
        running = true;
        dispatcherThread = Thread.ofVirtual().name("scheduler-dispatcher").start(this::dispatchLoop);
        for (int i = 0; i < Runtime.getRuntime().availableProcessors(); i++) {
            workers.submit(this::workerLoop);
        }
    }

    public void stop() throws InterruptedException {
        running = false;
        election.resign();
        if (dispatcherThread != null) dispatcherThread.interrupt();
        workers.shutdownNow();
        workers.awaitTermination(5, TimeUnit.SECONDS);
    }

    // ── Submission ────────────────────────────────────────────────────────────

    public String submit(Runnable task, long delayMs, int priority,
                         int maxRetries, long retryDelayMs, Set<String> dependencies) {
        Job job = new Job(task, System.currentTimeMillis() + delayMs,
                priority, maxRetries, retryDelayMs, dependencies);
        jobIndex.put(job.jobId, job);
        if (job.status == JobStatus.PENDING) enqueue(job);
        return job.jobId;
    }

    public JobStatus getStatus(String jobId) {
        Job job = jobIndex.get(jobId);
        return job == null ? null : job.status;
    }

    // ── Dispatch Loop ─────────────────────────────────────────────────────────

    private void dispatchLoop() {
        while (running) {
            try {
                long sleepMs = 10L;
                heapLock.lock();
                try {
                    // Promote WAITING_DEPS jobs whose dependencies are all DONE
                    for (Job job : new ArrayList<>(jobIndex.values())) {
                        if (job.status == JobStatus.WAITING_DEPS && depsResolved(job)) {
                            job.status = JobStatus.PENDING;
                            heap.add(job);
                        }
                    }
                    // Dispatch all due PENDING jobs
                    long now = System.currentTimeMillis();
                    while (!heap.isEmpty() && heap.peek().runAtMs <= now) {
                        Job job = heap.poll();
                        if (job.status == JobStatus.PENDING) {
                            job.status = JobStatus.RUNNING;
                            readyQueue.put(job);
                        }
                    }
                    if (!heap.isEmpty()) sleepMs = Math.max(1, heap.peek().runAtMs - now);
                } finally { heapLock.unlock(); }

                Thread.sleep(Math.min(sleepMs, 50L));
            } catch (InterruptedException e) { Thread.currentThread().interrupt(); break; }
        }
    }

    private boolean depsResolved(Job job) {
        return job.dependencies.stream()
                .map(jobIndex::get)
                .allMatch(dep -> dep != null && dep.status == JobStatus.DONE);
    }

    // ── Worker Loop ───────────────────────────────────────────────────────────

    private void workerLoop() {
        while (running && !Thread.currentThread().isInterrupted()) {
            try {
                Job job = readyQueue.poll(100, TimeUnit.MILLISECONDS);
                if (job != null) execute(job);
            } catch (InterruptedException e) { Thread.currentThread().interrupt(); break; }
        }
    }

    private void execute(Job job) {
        try {
            job.task.run();
            job.status = JobStatus.DONE;
        } catch (Exception ex) {
            int attempt = job.attempts.incrementAndGet();
            if (attempt < job.maxRetries) {
                long delay = job.retryDelayMs * (1L << (attempt - 1));
                job.runAtMs = System.currentTimeMillis() + delay;
                job.status = JobStatus.PENDING;
                enqueue(job);
            } else {
                job.status = JobStatus.FAILED;
            }
        }
    }

    private void enqueue(Job job) {
        heapLock.lock();
        try { heap.add(job); }
        finally { heapLock.unlock(); }
    }
}

import org.junit.jupiter.api.Test;
import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicInteger;
import static org.junit.jupiter.api.Assertions.*;

class JobSchedulerTest {

    @Test
    void basicJobExecution() throws Exception {
        JobScheduler scheduler = new JobScheduler(2, "node-1");
        scheduler.start();
        CopyOnWriteArrayList<String> results = new CopyOnWriteArrayList<>();

        scheduler.submit(() -> results.add("job1"), 0, 0, 1, 100L, Set.of());
        Thread.sleep(200);
        scheduler.stop();

        assertTrue(results.contains("job1"));
    }

    @Test
    void delayedJobRunsAfterDelay() throws Exception {
        JobScheduler scheduler = new JobScheduler(1, "node-2");
        scheduler.start();
        CopyOnWriteArrayList<String> results = new CopyOnWriteArrayList<>();

        scheduler.submit(() -> results.add("delayed"), 150, 0, 1, 100L, Set.of());
        Thread.sleep(80);
        assertFalse(results.contains("delayed"), "Should not run before delay");
        Thread.sleep(200);
        assertTrue(results.contains("delayed"), "Should run after delay");
        scheduler.stop();
    }

    @Test
    void jobRetriesOnFailure() throws Exception {
        JobScheduler scheduler = new JobScheduler(1, "node-3");
        scheduler.start();
        AtomicInteger attempts = new AtomicInteger(0);
        String jid = scheduler.submit(() -> {
            if (attempts.incrementAndGet() < 3) throw new RuntimeException("flaky");
        }, 0, 0, 3, 20L, Set.of());

        Thread.sleep(500);
        scheduler.stop();
        assertEquals(JobStatus.DONE, scheduler.getStatus(jid));
        assertEquals(3, attempts.get());
    }

    @Test
    void jobDependencyOrdering() throws Exception {
        JobScheduler scheduler = new JobScheduler(2, "node-4");
        scheduler.start();
        CopyOnWriteArrayList<String> results = new CopyOnWriteArrayList<>();
        CountDownLatch latch = new CountDownLatch(2);

        String idA = scheduler.submit(() -> {
            try { Thread.sleep(50); } catch (InterruptedException e) {}
            results.add("A");
            latch.countDown();
        }, 0, 0, 1, 100L, Set.of());

        scheduler.submit(() -> { results.add("B"); latch.countDown(); },
                0, 0, 1, 100L, Set.of(idA));

        latch.await(3, TimeUnit.SECONDS);
        scheduler.stop();

        assertTrue(results.indexOf("A") < results.indexOf("B"), "B must execute after A");
    }
}
